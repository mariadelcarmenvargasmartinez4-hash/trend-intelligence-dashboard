# Trend Intelligence Dashboard

Dashboard web construido con:

- Flask
- NewsAPI
- YouTube API
- OpenAI API (solo funciona si hay API Key cuando se paga saldo)
- Bootstrap 5

##  Features

- Búsqueda de noticias y videos por palabra clave
- Análisis de tendencias con score numérico
- Integración opcional de IA para análisis experto
- Dashboard moderno con diseño tipo oscuro
- Visualización de resultados en tarjetas y listas
- Texto de tendencias en rojo para resaltar sobre el fondo oscuro
